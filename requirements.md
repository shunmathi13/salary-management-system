# Employee Salary Management System

## 1. Goal
Build a web-based application that helps ACME's HR Manager manage salary information for 10,000 employees across multiple countries without relying on Excel spreadsheets.

## 2. Scope and Features
- View and search employee records.
- Add and update employee details.
- Manage employee salary, currency, country, and department.
- Filter employees by country, department, and salary range.
- Display salary summaries and dashboard statistics.
- Store employee and salary information in a relational database.
- Provide a React-based user interface and Python backend.
- Seed the database with 10,000 sample employees.
- Include automated tests for core functionality.

## 3. Out of Scope
- Actual salary payments and payroll processing.
- Tax calculations.
- Integration with external banking or HR systems.
- Advanced AI-based salary recommendations.

These features are excluded to keep the initial version focused on employee salary management and reporting.

## 4. Design Considerations
Use a maintainable architecture, validated APIs, database indexes, and pagination. Protect sensitive salary information with authentication and authorization before production use. Use automated tests and incremental Git commits to demonstrate development progress.
